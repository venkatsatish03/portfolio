## ✨ Key Features

### 🎨 Editorial Design System & Fluid Typography
- **Harmonious Palette**: Warm editorial paper palette for Light Mode (`#ebe6df`) paired with a sleek cyber-dark mode (`#0d0d0f`) using custom HSL/RGB design tokens.
- **Modern Typography**: Inter variable, Plus Jakarta Sans, and Space Grotesk / JetBrains Mono font pairings for crisp readability and editorial hierarchy.
- **Zero-Flicker Theme Engine**: Client-side theme detection with inline header scripts preventing white/dark flashes, coupled with local storage persistence.

### 💻 Interactive Hacker Dossier Terminal
- **Retro CRT Aesthetic**: Embedded interactive terminal overlay with CRT scanline raster effects, phosphor glow, and live tokenized syntax highlighting.
- **Dynamic Typing Engine**: Simulated keystroke cadence with contextual delays for punctuation and indentation, accompanied by playback controls (**Play**, **Pause**, **Skip**, **Replay**, and **One-Click Copy**).

### 🛠️ Featured Engineering Work & Modal Drilldown
- **Asymmetric Grid Showcase**: Visual display of flagship projects with high-impact metadata (indices, release years, category tags, and key architectural metrics).
- **Interactive Deep-Dive Modal**: Detailed architecture blueprints, problem-solution breakdowns, live application links, and GitHub repository access.

### ⚡ Capabilities & Technical Domains
- Interactive, categorized capability rows detailing deep expertise in:
  1. **Blockchain & Decentralized Architecture** (Solidity, Algorand, Smart Contracts, Cryptography, SHA-256)
  2. **Full-Stack Systems & API Engineering** (React.js, TypeScript, Node.js, FastAPI, Spring Boot, PostgreSQL)
  3. **Applied AI & Computer Vision Pipelines** (YOLOv8, EasyOCR, Real-ESRGAN, Scikit-learn, NLP)
  4. **Security, Cloud & Infrastructure** (Docker, AWS, Azure, OWASP, Kali Linux)

### 📈 Career Timeline & Accolades
- **Experience Timeline**: Structured overview of roles at **TSAROLABS Pvt. Ltd.** (AI & Cybersecurity Intern), **Oasis Infobyte**, and **Algorand Blockchain Club** (Lead).
- **Achievements & Certifications**: Showcasing honors from SIH 2025, Algorand Web3 Hackathon, TCS CodeVita Season 12, AWS Cloud Practitioner, Azure AI-900, and MongoDB Associate Developer.

### 📱 Performance & Accessibility
- **Fully Responsive**: Fluid layout scaling from mobile viewports to ultra-wide displays with a mobile navigation drawer.
- **A11y Compliant**: Semantic HTML5 landmark tags (`<main>`, `<nav>`, `<section>`, `<article>`), accessible skip-to-content link, high contrast ratios, and keyboard navigation.

## ⚙️ Getting Started

### Prerequisites

- **Node.js**: `v18.0.0` or higher
- **npm**: `v9.0.0` or higher (or `pnpm` / `yarn`)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/venkatsatish03/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser to view the application with hot module replacement (HMR).

## 🔧 Customization Guide

All portfolio content is decoupled from UI presentation and resides within a single, strictly-typed data file:

### 1. Update Personal & Professional Info
Edit [`src/data/portfolioData.ts`](file:///c:/Projects/Portfolio/src/data/portfolioData.ts):
- Update `personal` (name, title, tagline, social links, resume path).
- Update `education` (university, GPA, duration, specialization).
- Update `experiences` with your career journey.
- Add or modify `projects` with tags, descriptions, metrics, and live URLs.
- Update `skills`, `certifications`, and `achievements`.

### 2. Configure Theme Tokens & Colors
Modify the CSS custom properties in [`src/styles/index.css`](file:///c:/Projects/Portfolio/src/styles/index.css):
- `--portfolio-color-background`
- `--portfolio-color-surface`
- `--portfolio-color-accent-primary`
- `--portfolio-color-text-primary`

### 3. Replace Resume & Media Assets
- Place your updated resume PDF in `public/resume/Venkat_Satish_Resume.pdf`.
- Store any new project logos or screenshots in `public/images/`.

## 🚢 Deployment

The portfolio can be built into a static bundle and deployed to any modern hosting service:

### Deploying to Vercel

```bash
npm install -g vercel
vercel
```
Or connect your GitHub repository directly to [Vercel](https://vercel.com/) (Framework preset: `Vite`).

### Deploying to Netlify

1. Build command: `npm run build`
2. Publish directory: `dist`

### Deploying to GitHub Pages

Run `npm run build` and publish the generated `dist/` folder via GitHub Actions or the `gh-pages` package.
