# Portfolio

Milestone 1 scaffold for the personal portfolio website.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- ESLint
- Prettier

## Setup

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Run linting:

```bash
npm run lint
```

Check formatting:

```bash
npm run format:check
```

Apply formatting:

```bash
npm run format
```
